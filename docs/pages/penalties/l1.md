# L1 (lasso)

The L1 penalty sets individual coefficients exactly to zero. Its diamond-shaped
constraint region has corners on the coordinate axes, which favor sparse
solutions. At zero strength, the penalty vanishes.

$$
  P(\theta) = \lambda\sum_{j=1}^p|\theta_j|.
$$

## Constraint region

![Feasible region for l1 (lasso); the shaded set includes its
boundary.](figures/l1.svg)

$\lambda = 1$: $|\theta_1| + |\theta_2| \leq 1$. See the [plot
conventions](index.md#read-the-constraint-plots) for the fixed budget and
coefficient scale.

## Use the penalty

```rust
use shrinkage::{L1, Penalty, ProximalPenalty};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let penalty = L1::new(0.5);
    let coefficients = [2.0, -1.0];
    println!("Penalty: {}", penalty.value(&coefficients)?);
    let mut shrunk = [0.0; 2];
    penalty.prox(&coefficients, 1.0, &mut shrunk)?;
    println!("Proximal result: {shrunk:?}");
    Ok(())
}
```

Use [coordinate descent](../reference/solvers/coordinate-descent.md) for
Gaussian lasso, [IRLS](../reference/solvers/irls.md) for Gaussian or binomial
datafits, or [proximal gradient](../reference/solvers/proximal-gradient.md). The
exact proximal map is soft-thresholding at the step size times the strength. The
named [Lasso model](../models/lasso.md) provides the Gaussian convenience API.
